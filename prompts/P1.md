\# P1 Prompts



Prompts used for P1 (Department Assignment Puzzle, Reloaded), copied word for word, in the order they were sent.



\## Prompt 1: understanding the problem



> just explain me the entire q1 once and everything to be done in simple terms before proceeding with the codes



Result: explanation of the puzzle, the solution format and the three tasks (P1.a, P1.b, P1.c). No code.





\## Prompt 2: candidate generator



> ok ill do prolog q1



Result: candidate/1, which generates all 13,824 assignments (each attribute a permutation of its four values).





\## Prompt 3: candidate generator (repeat)



> give me the candidate code



Result: the same candidate/1 code again. Committed as `feat(p1): add candidate generator`.





\## Prompt 4: clues 1 to 4



> Write clue/2 clauses for clues 1 to 4 of P1, one clause per clue, each succeeding exactly when that clue holds in a fully filled-in solution.



Result: clue/2 clauses for clues 1-4 using memberchk/2. Candidates passing clues 1-4: 208.



\## Prompt 5: clues 5 to 8



> add clues 5-8 in the code



Result: clue/2 clauses for clues 5-8. Candidates passing all of clues 1-8: 3.



\## Prompt 6: main



> generate the code for calculating the main solution from all the clues



Result: satisfies/2 (candidates passing a chosen list of clues), print\_person/1 and main/0. main prints one solution of clues 1-8 in the required format.
